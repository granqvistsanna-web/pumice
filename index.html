Pumice

A soft, warm-grey system for component libraries and product showcases. Pills for every control, 28px cards for every stage, ink washes instead of borders, and motion that springs a little.

Use the tokens Source

Principles

Two shapes, nestedControls are pills. Stages and panels are 28px cards. Anything inside takes the outer radius minus its padding: a 22px menu holds 18px rows; slider rows are 10px.
Wash, don't outlineFills are ink at 6% alpha, so they tint whatever sits behind them. Borders are rare. Shadows are kept for what floats: three steps, each with one job.
Ink is the accentThe primary action is a near-black pill. Signal colors belong to content and demos, never to chrome.
Content shows on hoverCard names and actions rest hidden and spring up on hover or focus. The demo inside the card is the headline.

Depth

3D is for one object on a stage, never for chrome. Every scene shares one perspective, --depth 900px, and keeps its angles small. With reduced motion, --tilt goes to 0 and each scene holds its rest pose.

RuleDetail
One objectA scene holds one thing on a surface stage, often on the blueprint grid. Text and controls stay flat.
Small anglesTilt up to 10°, a turned stack 26°, a standing object 24° by 30°. Layers inside a card sit 18–56px forward.
Follow, then settleWhile the pointer moves, a 120ms linear follow; on leave, 700ms spring-soft back to rest.
LightA sheen in pane follows the pointer. The shadow stays on the floor and blurs as the object rises.
Keep it flat-safepreserve-3d breaks under overflow: hidden, so the stage clips, not the object. With reduced motion the scene holds its rest pose and the swap jumps without the drop.

How it works

The card reads where the pointer is as a number from −1 to 1 on each axis, then turns away from it by up to the tilt angle. Everything else is CSS: one perspective on the stage and three layers set forward in depth.

  1. Put the card on a stage with perspective: var(--depth).
  2. Give the card preserve-3d and push each layer forward with translateZ.
  3. Set --px and --py on pointer move; clear them on leave.

Code

.tilt {
  transform: rotateX(calc(var(--py) * var(--tilt) * -1))
             rotateY(calc(var(--px) * var(--tilt)));
  transition: transform 700ms var(--spring-soft);
}

Theme switch: flip the theme inside a view transition and tokens.css wipes it in from the toggle. Try the moon in the bar.

function setTheme(next, from) {
  var root = document.documentElement;
  var flip = function () { root.dataset.theme = next; };
  if (!document.startViewTransition) return flip();
  var r = from.getBoundingClientRect();
  root.style.setProperty("--vt-x", r.left + r.width / 2 + "px");
  root.style.setProperty("--vt-y", r.top + r.height / 2 + "px");
  document.startViewTransition(flip);
}
toggle.onclick = function () {
  setTheme(document.documentElement.dataset.theme === "dark" ? "light" : "dark", toggle);
};
